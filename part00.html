От переводчика

Это перевод на русский язык свободной онлайн-книги Майкла Нильсена «Neural Networks and Deep Learning» (neuralnetworksanddeeplearning.com), распространяемой по лицензии Creative Commons Attribution-NonCommercial 3.0. Перевод сделан по LaTeX-версии книги, подготовленной Антоном Владыкой (github.com/antonvladyka).

Несколько замечаний о том, как устроен перевод.

  • Формулы, нумерация уравнений и ссылки перенесены без изменений; переведены только текстовые вставки внутри формул (например, «выход» вместо «output»).

  • Код. В листингах переведены комментарии и строки документации, а сам код оставлен как в оригинале. Код книги написан для Python 2.7. Если вы работаете с Python 3, воспользуйтесь портом github.com/unexploredtest/neural-networks-and-deep-learning.

  • Иллюстрации. Графики, построенные прямо в LaTeX, переведены. Растровые рисунки (схемы сетей, графики обучения) взяты с сайта книги, поэтому подписи на них остались на английском. Самые частые подписи: input layer — входной слой, hidden layer — скрытый слой, output layer — выходной слой, inputs/output — входы/выход, Epoch — эпоха, Accuracy on the test (training) data — точность на тестовых (обучающих) данных, Cost — стоимость, Weight — вес, Bias — смещение.

  • Интерактивные элементы сайта (особенно в главе 4) в LaTeX-версии заменены статичными рисунками.

  • Числа. В формулах и коде десятичный разделитель — точка, как в оригинале и в языках программирования.

  • Термины переведены единообразно по всей книге. Основные: cost function — функция стоимости, bias — смещение, mini-batch — мини-пакет, learning rate — скорость обучения, backpropagation — обратное распространение ошибки, overfitting — переобучение.
